# Mini-SOC

Projet de mise en place d'un Mini Security Operations Center
(SOC) pour la collecte, la surveillance et l'analyse
des événements de sécurité.

## Architecture

- data/: stockage des données
- models/: modèles Machine Learning
- src/: code source Python
- dashboard/: interface de visualisation
- config/: fichiers de configuration
- logs/: journaux du projet

## Technologies

- Ubuntu Linux
- Kali Linux
- Suricata
- Wazuh
- Python
- Git
